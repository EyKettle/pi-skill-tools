## 技能加载树

skill-tools 将技能储存为应用状态。
通过维护技能加载树管理上下文中的技能，取代可被工具结果重现的阅读途径。

通过尾部提示词（`tail-prompt` 扩展）挂载到上下文中，具体见[挂载章节](#挂载)。

## 行为

加载需要指明技能 ID，但不需要完整 ID。
详见[技能 ID 取用规则]。

加载技能主文档不会加载所有相关文件。
而卸载技能主文档会卸载所有相关文件。

批处理是原子事务，任意一条失败整批失败。

## 树的两层存储

| 层 | 介质 | 储存 |
| --- | --- | --- |
| 日志 | Pi 会话树 | 每次变更的差分 |
| 副本 | 会话状态 | 当前叶位置的完整状态 |

日志是状态在树上任意位置的真值。
副本是它的缓存，可丢弃重算。

上下文中加载的内容是副本。

### 日志

日志分两类：变动和基线。

**基线**承载完整状态。

**变动**拥有多种类型：

| 操作 | 载荷 |
| --- | --- |
| 加载 | 身份、路径、整份正文 |
| 替换 | 身份、行级差分 |
| 移除 | 身份 |

每次变更追加一条日志，一条日志携带该次变更的全部影响。

### 差分

一条「替换」日志携带的差分是行级的。
差分把两版正文的差异表示成若干块：每块给出旧文中的起始行、被替换的行数，以及替换进去的文本。
落盘的是块列表，每块包含坐标与替换文本；删除掉的旧文本由折叠中的状态提供。

行级差分取 Myers 1986 的 O(ND) 算法族：取 `diff`（jsdiff）的 `diffLines`。
它的默认值把末尾换行与 CR 保留为差异，重建因此是精确的。

Myers 的代价随编辑距离增长，产出前因此设一道中止闸，由 `timeout` 或 `maxEditLength` 触发。
中止，或差分的落盘量不小于正文本身时，该次「替换」改带整份正文。
局部改动落成一个小块，散落改动落成若干块，整篇重写落成整份正文。

## 折叠

折叠把一条路径还原成一个状态：以空状态为起点，路径上出现 `baseline` 时改以它为起点，沿 root 到目标叶逐条应用差分。

同一路径与同一日志必得同一状态；挂载文本因此只由状态决定。

折叠发生时机：启动之后（当副本标记不符时）与导航之后。

## 写入序

1. 取当前状态：读副本；其标记与路径不符时先按「偏离与修复」重算。
2. 解析身份，读取文件。
3. 对当前状态算差分。
4. 追加提交条目，随即读取叶 ID 作为该状态的标记。
5. 写副本。
   写被拒时内存与日志照常前进，落盘落后一次，由下次成功写补齐。
6. 重注册尾部段。

## 导航

`session_tree` 事件携带新叶 ID，触发一次重算：折叠到新叶，写副本，重注册段。

普通追加不触发该事件，常规路径不付折叠的代价。

## 偏离与修复

| 起因 | 判据 | 处置 |
| --- | --- | --- |
| 副本落后或超前（崩溃、写被拒、他进程写） | 副本标记与路径上最后一条提交条目的 ID 不符 | 丢弃副本，折叠重算 |
| 副本的版本或形状无法识别 | 解码时关闭式失败 | 视为无副本：路径上有条目则折叠，否则为空 |
| 历史曾有缺口 | 路径上存在 `baseline` | 从最近一条 `baseline` 起折叠 |
| 路径上没有任何提交条目 | 条目数为零 | 以副本为准 |
| 条目畸形或补丁应用失败 | 应用时结构化失败 | 折叠中止，改用副本，上报一次 |
| 磁盘文件在加载之后变化 | — | 不适用：状态是冻结副本 |

## 历史回溯

在导航发生后，通过 Pi 会话树中记录的提交条目，折叠到对应历史状态。

该功能可关闭。

关闭期间不追加条目，副本标记置空，挂载、变更接口与命令照常。
重新开启后的第一条条目是 `baseline`，把缺口补上；缺口之前的变更不可回溯。

不变量：

- 缺口之后的第一条条目是 `baseline`。
- 关闭期间的变更不入日志，且该事实被上报一次。

## 挂载

挂载遵循 tail-prompt 扩展的接口契约。
`id` 为 `skill-tools`，`position` 为 10，来源取 `text`。
正文随注册一起交付，与状态里的冻结副本同源。

每个条目使用 `<SKILL/>` 标签包裹，指明基本信息：

```text
<SKILL id="{skill-id}" path="{/path/to/SKILL.md}">
{content}
</SKILL>
```

> 多个技能之间没有空行

## 手动路径

| 命令 | 作用 |
| --- | --- |
| `/skill:loaded` | 当前加载集，并声明回溯是否可用 |
| `/skill:import <id…>` | 导入或刷新；无参数即重读全部已加载项 |
| `/skill:cancel <id…>` | 取消，级联同变更接口 |
| `/skill:clear` | 取消全部 |

所需 ID 为[技能 ID]，支持列表。
