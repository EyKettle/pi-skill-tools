# 状态化技能缓存

技能正文由会话状态承载。工具输出限制不再约束技能完整度，工具调用不再重现文本。

状态分两层：Pi 的会话树承载提交日志，session-state 承载物化副本。日志是状态
在树上任意位置的真值，副本是它的缓存，可丢弃重算。

## 两层存储

| 层 | 介质 | 存什么 |
| --- | --- | --- |
| 日志 | Pi entry，`customType` 为 `skill-tools-commit`，不进模型上下文 | 每次变更的差分 |
| 副本 | session-state，`pluginId` 为 `skill-tools`，作用域 `session` | 当前叶位置的完整状态 |

日志先于副本写入：副本可以重算，缺失的日志条目无法从副本补回。

副本是挂载的输入。挂载按请求发生，折叠要读整条路径，副本让挂载不依赖折叠成功：
一条畸形条目不该让正文从上下文里消失。

不变量：

- 副本永不覆盖日志。

## 提交条目

Pi 把条目追加在当前叶之后并推进叶，日志因此天然串在会话树上。每次变更追加一条
条目，一条条目携带该次变更的全部影响——取消一个技能时，技能本体与其全部相关
文件落在同一条条目里。

技能的身份只有一种实物：它的 ID。ID 完整展开，无条件含位置前缀；相关文件在其后接
`/{type/file-name}`——因此精准定位，且只随技能本身变化。路径与它只是临时关系：
技能迁移后路径会变而 ID 不变，内容与 ID 对应。
显示形态由 ID 派生，规则见 `tui-render.md`。

| 操作 | 携带 | 理由 |
| --- | --- | --- |
| 加载 | 身份、路径、整份正文 | 折叠要从「无」造出内容 |
| 替换 | 身份、行级差分 | 差分大小随改动量走 |
| 移除 | 身份 | 折叠只需删除 |

条目分两类：`delta` 携带上表的差分；`baseline` 携带整份状态。

不变量：

- 一条「加载」的正文在日志里出现一次。
- 一条「替换」的差分不超过整份正文。
- 日志按会话单调增长，不做回收。

## 差分

一条「替换」携带的差分是行级的。差分把两版正文的差异表示成若干块：每块给出
旧文中的起始行、被替换的行数，以及替换进去的文本。
落盘的是整份块列表，即每块的坐标与替换进去的文本；
删除掉的旧文本由折叠中的状态提供。

行级差分由 Myers 1986 的 O(ND) 算法族产出，取 `diff`（jsdiff）的 `diffLines`。
它的默认值把末尾换行与 CR 保留为差异，重建因此是精确的。

Myers 的代价随编辑距离增长，产出前因此设一道中止闸，由 `timeout` 或
`maxEditLength` 触发。中止，或差分的落盘量不小于正文本身时，
该次「替换」改带整份正文。
局部改动落成一个小块，散落改动落成若干块，整篇重写落成整份正文。

## 折叠

折叠把一条路径还原成一个状态：以空状态为起点，路径上出现 `baseline` 时改以它为
起点，沿 root 到目标叶逐条应用差分。

同一路径与同一日志必得同一状态；挂出文本因此只由状态决定。

折叠只在两处发生：启动之后（当副本标记不符时）与导航之后。

## 写入序

1. 取当前状态：读副本；其标记与路径不符时先按「偏离与修复」重算。
2. 解析身份，读取文件。
3. 对当前状态算差分。
4. 追加提交条目，随即读取叶 ID 作为该状态的标记。
5. 写副本。写被拒时内存与日志照常前进，落盘落后一次，由下次成功写补齐。
6. 重注册尾部段。

## 导航

`session_tree` 事件携带新叶 ID，触发一次重算：折叠到新叶，写副本，重注册段。

普通追加不触发该事件，常规路径不付折叠的代价。

## 偏离与修复

| 起因 | 判据 | 处置 |
| --- | --- | --- |
| 副本落后或超前（崩溃、写被拒、他进程写） | 副本标记与路径上最后一条提交条目的 ID 不符 | 丢弃副本，折叠重算 |
| 副本的版本或形状无法识别 | 解码时关闭式失败 | 视为无副本：路径上有条目则折叠，否则为空 |
| 历史曾有缺口 | 路径上存在 `baseline` | 从最近一条 `baseline` 起折叠 |
| 路径上没有任何提交条目 | 条目数为零 | 以副本为准 |
| 条目畸形或补丁应用失败 | 应用时结构化失败 | 折叠中止，改用副本，上报一次 |
| 磁盘文件在加载之后变化 | — | 不适用：状态是冻结副本 |

## 历史开关

开关读 `{agent_dir}/settings.json` 的 `skills.history.enable`，缺省为开启。文件
直接从磁盘读，不经设置的写入通道。

关闭期间不追加条目，副本标记置空，挂载、变更接口与命令照常。重新开启后的第一条
条目是 `baseline`，把缺口补上；缺口之前的变更不可回溯。

不变量：

- 缺口之后的第一条条目是 `baseline`。
- 关闭期间的变更不入日志，且该事实被上报一次。

## 挂载

挂入点是 tail-prompt 的段契约：一段，`id` 为 `skill-tools`，`position` 为 1，
来源取 `text`，正文随注册一起交付，与状态里的冻结副本同源。

块是状态的一次渲染：按加载顺序逐项包裹为属性化块，条目之间以空行相接；集合为空
时交出空串。

段在三处注册：启动时、收到 `tail-prompt:ready` 时、状态变更与导航之后。

不变量：

- 挂出文本是状态的函数。
- 正文不在工具结果中出现。

## 变更接口

| 操作 | 输入 | 结局 |
| --- | --- | --- |
| 加载 | 身份或身份列表 | 新增、替换、或未变 |
| 取消 | 身份或身份列表 | 带子路径的身份只删该项；技能身份删本体及其全部相关文件 |
| 管理 | 加载列表与取消列表 | 一次事务同时表达两个方向 |

一批是原子的：任一身份不合法，整批不落地。取消一个未加载的身份有确定的失败结局。

## 手动路径

| 命令 | 作用 |
| --- | --- |
| `/skill:loaded` | 当前加载集，并声明回溯是否可用 |
| `/skill:import <id…>` | 导入；无参数即重读全部已加载项 |
| `/skill:cancel <id…>` | 取消，级联同变更接口 |
| `/skill:clear` | 取消全部 |

启动之前 Pi 尚未交出已加载集，而索引的遮蔽规则会丢弃不在活动集里的扫描结果，
预置加载必然失败。活动集为空时，标准根扫描的结果直接作为索引。

## 失败与上报

工具面向的闭集补四个状态：取消未加载的身份、批量为空、批量项类型非法、
管理里同一身份出现在两个列表。

历史层另有三条上报，不经工具结果：折叠中止、缺口之后的首条 `baseline`、路径没有
日志覆盖。同一原因只报一次。
